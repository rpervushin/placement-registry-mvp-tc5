# Placement Registry MVP — ТС5

Реестр плейсментов товарных подборок для мобильного приложения ТС5. 
Интеграция с RecSys для получения информации о плейсментах. Интеграция с MS Catalog для получения метрик по плейсментам.

## Содержимое репозитория

- [`ARCHITECTURE.md`](./ARCHITECTURE.md) — архитектура сервиса: стек, слоистая структура,
  доменная модель, интеграции, открытые вопросы.
- [`TASKS.md`](./TASKS.md) - первичные задачи по разработке и развертыванию сервиса.
- [`prototypes/`](./prototypes) — интерактивные HTML-прототипы (учётка плейсментов, карта
  плейсментов, требования к интеграциям). Открываются прямо в браузере, без сборки.
- [`diagrams/`](./diagrams) — подготовка диаграмм для согласования архитектуры C2 и DD.


## Статус

Сейчас зафиксированы архитектура и прототип UI. Кодовый скелет сервиса (FastAPI, по образцу
эталонного сервиса MS Catalog) и C4-диаграммы пока в работе, появятся отдельными коммитами.
